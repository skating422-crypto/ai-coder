📦 Devin 产品线全景（调研整理）

Cognition AI 的 Devin 生态：云端自主工程师 + 本地 IDE/CLI 客户端 + API 平台

☁️ Devin Cloud（app.devin.ai）

  • 云端会话：每个任务独立云端 VM（shell / 浏览器 / 编辑器），可长时间自主运行
  • 无限并行：批量子会话拆解大型任务（如上万文件的框架升级）
  • Devin Wiki：自动生成并定期刷新仓库文档
  • Devin Search / Ask Devin：面向代码库的深度问答
  • Devin Review：PR 自动代码审查
  • Knowledge / Playbooks：沉淀团队知识与可复用任务流程
  • Automations & Schedules：定时 / 事件触发的离线任务
  • 环境蓝图 + 快照：声明式开发环境，秒级启动

🖥️ Devin Desktop / IDE 客户端

  • 基于 VS Code 界面的桌面 IDE，内置 Devin Local 智能体面板
  • 聊天、写码、跑码一体；支持 Open VSX 扩展市场
  • 本地任务：直接修改本机工作区，适合快速迭代
  • 远端接力：一键把任务交给 Cloud Devin，本地实时看进度
  • 任务完成后拉回代码到本地继续开发 / 执行

⌨️ Devin CLI

  • 命令行本地编码智能体，终端内直接对话改码
  • 支持把任务 hand off 给云端 Devin 继续执行
  • 适合脚本化 / SSH 远程 / 无 GUI 场景

🔌 API 与集成

  • Devin API：编程式创建会话、获取结构化结果，接入 CI/CD
  • 服务账号 + RBAC，安全可审计
  • Slack / Jira / Linear / GitHub 集成：@Devin 直接派任务
  • MCP：连接外部工具与数据源
维度💻 本地（Desktop/CLI）☁️ 远端（Cloud）
运行位置用户本机工作区独立云端 VM（环境快照秒启）
适合任务快速小改动、实时结对长耗时、自主、多并行、离线任务
客户端关闭后停止继续运行，进度可随时回看
产出交付直接写入本地文件PR / 分支，可拉回本地执行
